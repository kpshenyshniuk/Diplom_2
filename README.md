API Тестирование Stellar Burgers

Описание проекта
Этот проект предназначен для автоматизированного тестирования API сервиса Stellar Burgers. Он использует Python, pytest и requests для проверки основных функций API, таких как регистрация пользователей, авторизация, создание заказов и обновление профиля.
Используемые технологии
Python – язык программирования
pytest – фреймворк для тестирования
requests – библиотека для отправки HTTP-запросов

Установка и запуск тестов
1. Установка зависимостей

Убедитесь, что у вас установлен Python 3, затем выполните:
pip install -r requirements.txt

2. Запуск тестов

Для запуска всех тестов:
pytest tests/

Запуск конкретного теста:
pytest tests/test_create_user.py

Выполняемые проверки
Проект тестирует следующие сценарии:

✅ Создание нового пользователя – проверка API /api/auth/register
✅ Авторизация пользователя – проверка API /api/auth/login
✅ Обновление профиля пользователя – проверка API /api/auth/user
✅ Создание заказа – проверка API /api/orders
✅ Получение списка заказов пользователя – проверка API /api/orders
